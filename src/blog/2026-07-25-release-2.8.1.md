We just released two patch versions of AiiDA, v2.8.1 and v2.7.4.

Both fix a SQLite `QueryBuilder` regression where filters such as `{'ctime': {'in': [...]}}` or `{'ctime': {'!in': [...]}}` with Python `datetime` values could fail.
Plugins that select or exclude nodes by creation or modification time work again on SQLite profiles.

Both releases also add a migration that downgrades a version 10 configuration schema, introduced in the upcoming v2.9.0, back to the version 9 schema used by the 2.7 and 2.8 series.
This means you can try out v2.9.0 and go back to your previous version without having to fix up `config.json` by hand.

You can find the full list of changes in the CHANGELOG for [v2.8.1](https://github.com/aiidateam/aiida-core/blob/v2.8.1/CHANGELOG.md#v281---2026-07-25) and [v2.7.4](https://github.com/aiidateam/aiida-core/blob/v2.7.4/CHANGELOG.md#v274---2026-07-25).

Happy computing!
